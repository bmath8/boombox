# Development notes

Working notes written while BoomBox was being built: sprint summaries, setup guides and checklists.
They are kept as a record and were not rewritten afterwards.

Read them with that in mind. Where a note says "deployed", "complete" or "operational", it means the piece was set up and
running on my own machine. BoomBox is a prototype: it has not been deployed publicly or run under real load.
File paths inside these notes are written from the repository root.
